# Toolmera

Premium, privacy-first online utility platform.

## Stack
- Next.js App Router
- Static export (`output: 'export'`)
- Client-side image/PDF/text/calculator processing
- Designed for Cloudflare static deployment

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
Static output is generated in `out/`.
